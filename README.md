Sky Courier: Island Run — fly the Kestrel-2 over a six-island archipelago in a chase or cockpit view with full instruments (heading, speed and altitude tapes, artificial horizon, throttle/fuel/airframe gauges). Thread a six-ring course, hop between two runway strips, or run cargo to a beacon through gusty wind on half a tank. Throttle and turn discipline, stall behaviour, flaps, gear, fuel burn and touchdown quality all matter: grease it or write the plane off. Keyboard and mouse, no build step, no network — open `game/index.html` in desktop Chrome and fly.

## Run it

```sh
node serve.ts
# then open http://localhost:8902
```
